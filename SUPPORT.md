# Support and bug reports

Please report reproducible bugs through the repository's structured
[bug report form](../../issues/new?template=bug_report.yml). One issue should
describe one problem.

## Files to include

- `latest.log` from the game session in which the problem occurred
- the matching file from `crash-reports` if Minecraft crashed
- a complete list of installed mods and their versions
- screenshots or a short video for visual, animation, or rendering problems
- the shader pack, resource packs, and rendering mods in use

In the standard Minecraft launcher installation, `latest.log` is usually in
`.minecraft/logs/latest.log`, while crash reports are in
`.minecraft/crash-reports/`. Third-party launchers normally provide an option
to open the instance folder; its `logs` and `crash-reports` folders contain the
same files.

Drag files directly into the corresponding GitHub issue field or upload them
to a paste service and provide the link. Complete logs are more useful than a
single copied error line.

## Before submitting

1. Check whether the problem still occurs with the newest release for your
   Minecraft version.
2. Search existing issues for the same symptoms.
3. If practical, reproduce it without unrelated mods, shaders, or resource
   packs. Mention the result in the report.
4. Never publish passwords, access tokens, e-mail addresses, server addresses,
   or other private information. Review logs before uploading them.
