# **![](https://media.forgecdn.net/attachments/1052/219/curseforge_logo.png)**

![Souls Like Bosses: Reforged](https://media.forgecdn.net/attachments/1841/505/curseforge_title-png.png)

Souls Like Bosses: Reforged brings four cinematic, multi-phase boss fights to
Minecraft. Each encounter includes custom models, animations, attacks, arenas,
rewards, and extensive configuration options.

## Supported versions

| Minecraft | Mod loader |
| --- | --- |
| 1.20.1 | Forge |
| 1.21.1 | NeoForge |

# **Required Mods**

- [Huge Structure Blocks](https://www.curseforge.com/minecraft/mc-mods/huge-structure-blocks)
- [GeckoLib](https://www.curseforge.com/minecraft/mc-mods/geckolib)

# **Boss Battles**

- **The Nightlord**
- **Melkor, Eraser of Time**
- **Soul of Cinder**
- **Abyss Watchers**

# **Boss Arenas**

- **Tree of Light** — generates inside the ocean biome
- **Melkor's Keep** — generates inside the soul sand valley
- **Kiln of the First Flame** — generates on jagged peaks and frozen peaks
- **Catacombs of Carthus** — generates inside the deep dark

# **Configuration**

The mod includes a server config that lets you adjust the difficulty of the
fights and the weapon drops:

- Health Multiplier
- Damage Multiplier
- Armor Multiplier
- Speed Multiplier
- Attacks Per Combo
- Weapon damage, durability, cooldowns, and more

# **Found a Bug?**

Please use the structured [bug report form](../../issues/new?template=bug_report.yml).
It asks for the information needed to reproduce and diagnose the problem.
Before submitting, keep your `latest.log` and, if Minecraft crashed, the matching
crash report ready. See [Support and log files](SUPPORT.md) if you are unsure where
to find them.

Do not post access tokens, passwords, e-mail addresses, or other private data in
an issue or log file.
